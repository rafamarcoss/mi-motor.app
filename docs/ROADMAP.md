# MiMotor: roadmap

## P0: base pública

- [x] Deployment automático desde `main`.
- [x] Dominio, canonical, robots y sitemap.
- [x] Contratos y límites documentados.

## P1: calculadora

- [ ] Entrada breve de vehículo, origen, destino y conducción.
- [ ] Opciones avanzadas colapsadas.
- [ ] Resultado con explicación y rango.

## P2: datos deterministas

- [ ] Cálculo de consumo ajustado y casos reproducibles.
- [ ] Adapter de routing y geocoding.
- [ ] Adapter de precios medios oficiales de carburantes.
- [ ] Ficha normalizada de vehículos con fuente y fecha.

## P3+: backend y contenido

- [ ] Gateway serverless seguro y provider abstraction para IA.
- [ ] Rate limiting minimizado y cache.
- [ ] Plantilla `/articulos/` y contenido revisado.
- [ ] Páginas por vehículo solo cuando exista información útil.
