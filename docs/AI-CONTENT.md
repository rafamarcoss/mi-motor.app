# MiMotor: contenido asistido por IA

## Pipeline

Idea → investigación → esquema → borrador → fact check → SEO → imagen → validación → publicación.

La publicación automática queda desactivada hasta que cada afirmación factual tenga fuente revisable. No se inventan leyes, multas, precios, estadísticas ni especificaciones.

## Contratos

La capa IA recibe datos estructurados y devuelve JSON validado. Un adapter permite cambiar DeepSeek por otro proveedor sin tocar la calculadora. Las operaciones matemáticas, la distancia final y el coste no se delegan al LLM.

## Imágenes

Las imágenes editoriales serán realistas, sin logos, matrículas legibles, personas reconocibles, texto ni marcas de agua. El prompt se construye desde `topic`, `scene`, `environment`, `weather`, `road_type`, `vehicle_type`, `mood` y `avoid`.

## Revisión

Cada artículo necesita fuente, fecha de comprobación, CTA contextual y revisión de seguridad cuando mencione asistentes durante la conducción. Se recomiendan comandos de voz; nunca interacción manual peligrosa con el móvil.
