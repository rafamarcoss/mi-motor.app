# MiMotor

Herramientas prácticas para entender el consumo, coste y mantenimiento de un coche.

## Development

```sh
python -m http.server 8000
```

Abre `http://localhost:8000/`.

Las pruebas del cálculo se ejecutan con `node --test tests/calculator-core.test.js`.

## Deployment

GitHub Pages despliega automáticamente los cambios enviados a la rama `main`.
El dominio personalizado se configura en GitHub Pages con `mi-motor.app`.

Arquitectura y roadmap: `docs/ARCHITECTURE.md` y `docs/ROADMAP.md`.
